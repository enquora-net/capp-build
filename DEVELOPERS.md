# Developer Guide — capp-build

## Prerequisites

**Lisette** — required. Install from [lisette.run](https://lisette.run).
Confirm with `lis --version`.

**Go 1.26 or later** — required. See [go.dev/dl](https://go.dev/dl) or install
via MacPorts (`sudo port install go`) or Homebrew (`brew install go`).

**Zig** — required for cross-platform release builds. Install via MacPorts
(`sudo port install zig`) or Homebrew (`brew install zig`). Not required for
native development builds.

**tree-sitter-objj dynamic library** — required at runtime. Install from the
[tree-sitter-objj releases page](https://github.com/enquora-net/tree-sitter-objj/releases)
to `/usr/local/lib`. Confirm with `capp-build smoke`.

**gh (GitHub CLI)** — required for `make release` only.

## One-time environment setup

`capp-parse` is a private module. Two settings are required before `go` can
resolve it:

```sh
# Keep the Go module proxy out of the resolution path for private modules.
# Absent: fetch errors mentioning proxy.golang.org (404/410).
go env -w GOPRIVATE=github.com/enquora-net/*

# Route module fetches for the organisation over SSH.
# Absent: "terminal prompts disabled" / "could not read Username".
git config --global url."git@github.com:enquora-net/".insteadOf "https://github.com/enquora-net/"
```

## Build

```sh
# Compile and run (development)
lis run

# Native build to target/
make build-host

# All six platform targets (requires Zig, macOS host for Darwin targets)
make build-all

# Checksums only
make checksums
```

## Release workflow

1. Update `VERSION.txt` with the new version string.
2. Add a matching `## <version> — <date>` section to `CHANGELOG.md`.
3. Commit and push.
4. `make release`

The `release` target builds all platforms, computes checksums, creates a
GitHub release tagged `v<VERSION>`, extracts release notes from `CHANGELOG.md`,
and uploads all artifacts. Pre-release versions (any version containing a
hyphen) are marked as pre-releases on GitHub automatically.

---

## Updating the capp-parse pin

```sh
make bump-parse
```

Pins by commit hash. Never pin `@latest` or a branch name — those consult
the default branch and caching makes them non-deterministic. The branch the
commit is on is irrelevant; Go resolves any pushed commit by hash.

## Code standards

- `lis check` must be clean before any commit. `lis format` before every commit.
- `target/` is generated by the Lisette compiler. Never modify it by hand.
- `src/version_generated.lis` is generated by `make gen-version`. Never edit
  it by hand; it is restored to a `"dev"` sentinel after release builds by
  `make restore-version`.
- No capability in command handlers. All logic lives in the library packages
  under `src/build/`; command files are consumers only.
- Exhaustive `match` over all closed types. Catch-alls are only permitted at
  the CST firebreak (`lower.lis`), where tree-sitter erases the closed
  node-kind set to strings at the C boundary. A catch-all on a closed Lisette
  sum is a defect.
